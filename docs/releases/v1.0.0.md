# v1.0.0: V-Model Classic

**Released:** 2026-04-13
**Status:** Frozen. No further releases on the v1 line.

## Summary

First tagged release. Captures the V-Model Classic workflow as a frozen
reference point before the v2 restructuring begins.

v1.0.0 is available as a legacy snapshot for historical reference. It
is **not** distributed through the plugin marketplace. The recommended
installation path for new users is v2 (via the plugin marketplace on
Claude Code, Cursor, Codex, OpenCode, Gemini CLI, or Copilot CLI). See
the [Installation tutorial](../tutorials/installation).

## Features

- 8 Claude Code skills covering the full V-Model cycle:
  `project-conventions`, `business-analyse`, `requirements-engineering`,
  `architecture`, `coding`, `testing`, `security-audit`, `v-model-workflow`
- 3 innovation phases in `business-analyse`: Exploration, Ideation,
  Validation
- 20+ innovation methods with probing techniques (5-Why, Future
  Projection, Perspective Shift, Emotional Level, Analogy Trigger)
- Tech-agnostic Success Criteria enforcement in
  `requirements-engineering` with a forbidden-terms list
- Living documents pattern in the `coding` skill (ADR/Feature writeback
  during and after implementation)
- OWASP Top 10 and OWASP LLM Top 10 coverage in `security-audit`
- GitHub Copilot agents mirror under `.github/` for non-Claude-Code users
- Shell-based installer: `./install-skills.sh`

## What's NOT in v1.0.0 (added in v2)

- Multi-platform plugin distribution (Cursor, Codex, OpenCode, Gemini CLI)
- Claude Code plugin marketplace (`pssah4-skills`)
- Bootstrap skill `using-digital-innovation-agents` with SessionStart hook
- 5 new sub-phases in `/coding` (Task breakdown, optional TDD, Debugging
  protocol, Verification gate, Regression test cycle)
- Mandatory 3-part Handoff Ritual at the end of every phase skill
- `/testing` "Role alongside TDD" section
- `/v-model-workflow` Phase 7 Release Closure
- `_devprocess/context/20_bugs.md` and `30_handoffs.md` file conventions
- Full English translation (v1 had mixed German/English skills)

## Support Policy

v1.0.0 is **frozen**. No bug fixes, no security patches, no updates.
Users requiring new features or maintenance should use v2.

## Installation

```bash
git clone https://github.com/pssah4/digital-innovation-agents.git
cd digital-innovation-agents
./scripts/install-skills.sh --version v1.0.0
```

The script auto-detects the v1 directory layout (`claude-code-skills/`
instead of `skills/`) and installs the 8 phase skills to
`~/.claude/skills/`.
